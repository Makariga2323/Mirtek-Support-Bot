# Mirtek Support Bot

Интеллектуальный сервис автоматической обработки клиентских обращений ООО «Миртек».
Партнёрский проект Городского Классического Лицея и ООО «Миртек».

## Что делает сервис

Принимает вопрос клиента текстом, определяет, о чём он, находит данные в источниках
и формирует ответ. Если надёжный ответ невозможен, передаёт обращение оператору.

## Структура репозитория

- 'app/'    код сервиса
- 'tests/'  тесты
- 'data/'   данные
- 'docs/'   документация

## Как начать работу

1. Установите Git и войдите в GitHub.
2. Склонируйте репозиторий и перейдите на ветку `dev`:
git clone <URL репозитория>
cd mirtek-support-bot
git checkout dev

3. Прочитайте правила работы: [CONTRIBUTING.md](CONTRIBUTING.md).

## Ветки

- 'main/': релиз, стабильная версия
- 'dev/':  разработка
- 'feature/...':    отдельная ветка под каждую задачу
